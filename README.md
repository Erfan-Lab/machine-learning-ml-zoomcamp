## ✨ About This Repository

This repository contains my **code-along work, notebooks, experiments, and implementations** from the first six sections of **Machine Learning Zoomcamp** by **DataTalks.Club**.

The purpose of this repository is to document the practical work I completed while learning the fundamentals of Machine Learning and Machine Learning Engineering.

Rather than simply watching the lectures, I followed along by writing and experimenting with the code myself.

> **Learn → Code → Experiment → Understand**

This repository focuses specifically on **Sections 1–6** of the course.

---

## 🎯 What This Repository Covers

The six sections included in this repository cover a range of fundamental Machine Learning concepts:

* 🐍 Python, NumPy & Pandas
* 📊 Exploratory Data Analysis
* 📈 Linear Regression
* 🏷️ Classification
* 📐 Model Evaluation
* ⚙️ Feature Engineering
* 🎛️ Regularization
* 🚀 Model Deployment
* 🌳 Decision Trees
* 🌲 Ensemble Learning fundamentals

The notebooks contain implementations and experiments performed while following the course material.

The first complete Machine Learning workflow.

* Feature preparation
* Training models

* Regularization

Moving from predicting continuous values to predicting classes.

* Binary classification

* Model evaluation

* Model deployment
